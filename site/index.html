Paste into your coding agent. It builds a private localhost preview in an isolated worktree; your current checkout stays untouched.

Your docs have been sitting out back for years. The real knowledge is somewhere else: spaghetti code, comments, schemas, tests, half-finished specs, and whatever still makes sense in someone's head.

Poolboy turns that mess into a clean, agent-native knowledge surface — plain Markdown over HTTP, a graph.json, provenance, and stable links. Keep it private for the agents building your product, or publish it and show the world how your product works.

Go CLI built with Obsidian's Knap, Google's OKF, and zero web frameworks.Open the output in your IDE, Obsidian, GitHub, or any editor. No plugin, conversion, or sync layer required.

Install and build it yourself
npm install -g @grosspoetrysystems/poolboy
poolboy init .
poolboy check
poolboy build

Requires Node 22 or newer. poolboy init preserves existing files.
